# Drawgon

Domain: https://drawgon.in. Central configuration: `src/config/brand.ts`.

Logo: `public/drawgon-logo.png`, a black transparent mark combining a geometric d, dragon head and connected diagram nodes. Generated with the built-in image generation tool; used in the header, footer and favicon. The mark is an application branding asset, separate from the upstream Diagram Design identity.

Generation prompt: “Create one minimal, professional logo symbol for a web-based technical diagram maker named Drawgon (drawgon.in). Symbol only, no text, no wordmark, no mockup. Pure solid black geometric vector-like mark on a genuinely transparent background. Combine an abstract lowercase d silhouette with a subtle angular dragon head and two or three connected diagram nodes. Extremely simple, recognizable at 24px, clean uniform line weight, orthogonal geometry and negative space. No flames, gradients, shadows, color or orange. Center one compact square mark with modest transparent margin.”

Default diagram palette: Monochrome. Black/gray on white for light styles; white/gray on black for the optional dark style. Explicit accent-color mode is available in Diagram Settings. The application enforces monochrome paint conversion after sanitization; original licensed upstream references remain unchanged.
