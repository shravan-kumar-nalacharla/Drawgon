# Drawgon

Domain: https://drawgon.in. Central configuration: `src/config/brand.ts`.

Logo: `public/drawgon-logo.png`, the exact user-supplied black dragon and pen-nib mark from `ChatGPT Image Sep 8, 2026, 10_00_12 AM.png`. The original PNG is copied without redrawing, cropping, stretching or modifying its pixels. Used in desktop/mobile header, footer, favicon, generation loading state and OpenGraph/Twitter metadata. CSS uses `object-fit: contain` and multiply blending in light UI areas so the white paper blends with Drawgon's editorial background. The asset remains separate from upstream Diagram Design's identity.

The previous generated icon has been replaced. No generated approximation or additional font assets are used for the new logo.

Default diagram palette: Monochrome. Black/gray on white for light styles; white/gray on black for the optional dark style. Explicit accent-color mode is available in Diagram Settings. The application enforces monochrome paint conversion after sanitization; original licensed upstream references remain unchanged.
